# 创意策划节点使用说明

本次新增图片创意策划节点，不包括视频。

1. 点击画布工具栏“创意策划”，也可从新增节点菜单创建。
2. 将上传的产品图片、风格参考图连接到节点，为每张图选择用途。
3. 填写产品链接和制作要求，选择策划比例。也支持识别要求中的 HTTPS 链接。
4. 点击“运行创意策划”。使用软件已配置的文本模型分析图片与网页；请使用支持图片理解的文本模型。
5. 编辑画面描述、逐条编辑/新增/删除文案。最终 Prompt 自动更新，可预览和复制。
6. 将策划节点连接到图片节点，参考图自动继承。按现有图片节点选择模型、比例和清晰度后生成。
7. 比例不一致时选择使用提示词比例，或确认接受“图片展示不全”风险后使用下游比例。取消不生成。

网页读取失败会明确提示。可以补充产品资料后运行，也可确认仅根据已提供资料继续。AI 返回格式无效或请求失败时，原方案保留。重新运行会询问是否覆盖当前编辑。

节点信息随画布保存。输入变化会标记需要重新运行；文案编辑无需再次调用模型。此次未改变已有图片不自动裁切策略。

## 当前验证

- 类型检查和生产构建。
- 文案替换/删除不破坏手动画面描述。
- 生成输入继承两类图片、去重，不混入历史 Prompt。
- 公开网页读取地址边界。
- 已有图片不裁切测试。
