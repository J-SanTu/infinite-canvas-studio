# 白底图采用方案 A（取代 C）

用户于 2026-09-28 明确改选 A：使用无限画布的 4K、1:1 生图档位，随后按用户选择的 800、1600、2000 正方形尺寸导出 JPG。

采用 quality=high、size=1:1、count=1，与画布一致；当前适配器该档位为 2880×2880，并非 4096×4096。保留上游返回，再一次高质量等比缩放到最终画布，白色补边、不裁切。允许不足目标尺寸的输入插值放大，不承诺原生高清。这样避免先放大到 2880 再缩小的额外重采样。

每图仅一次模型调用，不再拦截低像素，不调用本地或云端超分。移除本次 C 新增接口、资源和打包配置；保留独立测试档案。压缩、按目录导出和历史记录继续沿用原流程。版本保持 0.5.0。
