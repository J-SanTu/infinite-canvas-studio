# 导演台使用指南（新手版）

导演台用于把无限画布中的人物、道具和场景组织成可预演、可截图、可导出的视频镜头。推荐顺序：新建工程 → 摆放对象 → 调整主摄像机 → 设置动作 → 预演 → 导出。

## 进入与保存

打开或新建导演台节点后等待已连接/已保存提示。每个节点都有独立工程，自动保存对象、镜头、动作、时间轴和摄像机设置。新画布同步有短暂延迟时，导演快照会先保存，下一次自动保存会补上画布关联。

## 对象列表

眼睛控制显示/隐藏，锁控制是否可拖动。点击名称或画布对象进行选择；添加人物用于摆姿势和动作，添加基础物体用于搭景，导入用于加入支持的模型或场景资源。对象重叠时按住 Alt 点击可选择前层对象。

## 工具栏与快捷键

- **Q 选择**：选择对象或人物关节。
- **W 移动**：整体移动对象。
- **E 旋转**：旋转对象；选中主摄像机时调整镜头方向。
- **R 缩放**：整体缩放对象。
- **世界/局部坐标**：沿场景轴或对象自身轴操作。
- **吸附**：开启后移动按 0.1 格、旋转按 5° 吸附；关闭后自由调整。

## 编辑视角与摄像机视角

编辑视角是摆场景用的观察相机，摄像机视角显示场景中“主摄像机 01”的真实画面，PNG 和 MP4 都以主摄像机为准。点击摄像机视角后，在空白处拖动旋转，右键拖动平移，滚轮缩放；变化会写回主摄像机。编辑视角中空白处左键旋转、右键平移、滚轮缩放。镜头角度用于调整地面和水平线参考。摄像机窗口可选择主摄像机、最小化、放大或切换视角；网格、光照和实体显示是辅助工具，网格不会进入导出。

## 人物摆姿与动作

选中人物后用 Q 点击关节并拖动。右侧面板提供归零旋转、归零缩放、落地、锁定、复制和保存自定义姿势。动作库中的连续动作可在时间轴预演和循环；固定姿势（例如“摇头右侧”单帧姿势）没有连续时长，因此循环按钮禁用是正常的。

## 时间轴

播放/暂停预演；拖动时间指针查看帧；设置 FPS 和时长决定播放与视频长度。选中对象后添加关键帧记录位置、旋转、缩放或姿势，拖动关键帧改变时间，复制/粘贴复用动作，插值决定平滑变化或停顿。

## 镜头、截图与导出

先选画面比例，再调整主摄像机构图。截图 PNG 会把当前主摄像机画面添加回无限画布；导出 MP4 按主摄像机、比例、FPS 和时长生成视频。导出前切换到摄像机视角检查人物是否出框、地面是否穿插、镜头是否锁定正确。

## 常见问题

- **保存失败**：确认后端已启动并等待几秒；新画布同步延迟时先继续编辑一次即可补关联。
- **摄像机拖不动**：确认已点击摄像机视角、锁定按钮为蓝色解锁状态，并在空白处拖动。
- **循环灰色**：当前是固定姿势，请改选动作库中的连续动作。
- **导出与编辑视角不同**：导出使用主摄像机，切换摄像机视角检查最终构图。
- **打开为空**：确认打开同一个导演台节点，并等待自动保存完成。

## 推荐练习

添加人物和平面，用 W 把人物放到平面上；进入摄像机视角完成一个近景；选择连续动作并添加起止关键帧；播放确认后导出一张 PNG，再导出 3 秒 MP4。
